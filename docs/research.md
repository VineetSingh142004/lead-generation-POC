# Epoxy flooring lead-page research

## Recommended direction

The strongest pattern for this category is not a generic contractor site. It is a visually-led, fast landing page: identify the project type quickly, make finished surfaces prominent, and retain one simple estimate action. That is the approach used in this POC.

## Decisions reflected in the build

| Finding | Applied decision |
| --- | --- |
| Epoxy is a visually judged purchase; specialist site reviews consistently put large, high-quality finished-floor imagery ahead of long sales copy. | The hero is material-led and the small finish gallery lets the visual work carry the page. |
| Residential and commercial visitors have different jobs to do. | The first decision is three explicit service pathways, which also preselect the lead-form value. |
| Lead pages work best when their primary request path is clear and low-friction. | The form asks only for name, phone, region, and service; the page has repeated but consistent quote CTAs. |
| The project brief explicitly forbids unsupported claims. | No ratings, years, certifications, locations, pricing, or turnaround promises are invented. |

## Template evaluation

Wix template discovery surfaced a Building Company template as the closest broad category. It is useful as a content inventory reference (project imagery, services, contact route), but its construction-language conventions do not match the stated Apple/Linear-inspired premium finish. The implementation therefore uses a bespoke white, charcoal, restrained gold, and steel palette with editorial typography instead of importing a template.
